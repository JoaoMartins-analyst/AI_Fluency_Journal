# João’s AI Fluency Journal

My practical learning journal for AI fluency, AI evaluation and software testing.

My goal is to pursue entry-level AI evaluation opportunities while developing Python and QA skills for more technical roles. This repository documents my notes, exercises, testing results and projects.

## Learning roadmap

The initial study block is approximately 12 weeks / 240 hours, adjusted to my pace. Progress is assessed through practical work and review checkpoints.

- [ ] **Anthropic AI Fluency: Framework and Foundations** — understand AI capabilities, limitations and the 4D framework.
- [ ] **Python fundamentals** — learn alongside AI: variables, functions, conditions, loops, collections, files and error handling.
- [ ] **Git and GitHub** — organise my work, track changes and document projects.
- [ ] **Manual AI evaluation** — follow guidelines, verify information, compare responses and apply consistent rating criteria.
- [ ] **Software testing fundamentals** — design test cases, define expected results, report defects and perform regression tests.
- [ ] **APIs and automation** — understand HTTP, JSON, authentication, API calls, errors, timeouts and retries.
- [ ] **Automated evaluation with Python** — run batches of tests, save results, use pytest and retain human review.
- [ ] **Retrieval and RAG basics** — build a document-grounded assistant and evaluate its citations and handling of missing information.
- [ ] **AI safety foundations** — explore prompt injection, OWASP guidance and authorised practice labs.
- [ ] **Portfolio projects** — develop two reproducible case studies showing results, limitations and improvements.
- [ ] **Career preparation** — review eligible roles, prepare applications and practise explaining my work.
