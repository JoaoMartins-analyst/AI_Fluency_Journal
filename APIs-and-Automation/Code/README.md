\# APIs and Automation Code



This folder is for scripts that connect to APIs and automate parts of an AI evaluation workflow.



Planned practice includes:



\- Sending HTTP requests and processing JSON responses.

\- Calling AI models through APIs.

\- Handling errors, timeouts and retries.

\- Running batches of evaluation cases.

\- Saving responses and test results.

\- Measuring usage, cost and response time where available.



Each script should explain its purpose, required setup, inputs and outputs.



API keys and other credentials must remain outside the published code.
